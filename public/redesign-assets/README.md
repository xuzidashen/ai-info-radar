# Redesign assets

本目录保存 `/redesign` 高保真界面的演示图片。当前 WebP 图片从用户提供的 UI 参考图中裁切，仅用于本地设计验证，没有复制参考图中的品牌、文字或完整界面。

## 当前文件

| 文件 | 用途 | 建议正式尺寸 |
| --- | --- | --- |
| `hero-city.webp` | 首页头条、AI 趋势文章主图 | 1600 x 720 |
| `ai-chip.webp` | AI 芯片文章与专题缩略图 | 1200 x 800 |
| `city-economy.webp` | 商业与城市文章缩略图 | 1200 x 800 |
| `satellite.webp` | 航天专题缩略图 | 1200 x 800 |
| `dna-tech.webp` | 科研资讯缩略图 | 1200 x 800 |
| `talent-city.webp` | 城市政策缩略图 | 1200 x 800 |
| `new-energy.webp` | 新能源资讯缩略图 | 1200 x 800 |
| `profile-avatar.webp` | 演示用户头像 | 512 x 512 |

## 后续替换要求

- 正式发布前应替换为自有、已授权或明确可商用图片。
- 文章图统一优先使用 `3:2` 或 `16:9`，主体位于画面中央偏上，避免列表裁切后失去重点。
- 用户头像建议正方形，不需要透明底。
- UI 图标全部来自 `@phosphor-icons/react`，不需要额外位图。
