# Brand Assets

This directory stores self-owned brand assets for AI 信息雷达 / Multi-Zone Intelligence Hub.

Current assets:

- `app-mark.svg`: compact radar mark for navigation, avatars, and small placements.
- `app-logo.svg`: horizontal logo for README, release notes, and presentation use.
- `../icons/app-icon.svg`: app icon source.
- `../splash/splash-light.svg`: light launch screen source.
- `../splash/splash-dark.svg`: dark launch screen source.

Rules:

- Use radar, information wave, and circular orbit shapes as the core visual language.
- Do not copy reference images into this project.
- Do not add unknown-license images.
- Before a store release, export density-specific Android PNG resources from the SVG sources.
