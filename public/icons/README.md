# Icons

This folder holds self-owned icon placeholders for the web product and APK preview.

- `app-icon.svg` is the source icon concept.
- Android adaptive icon resources are prepared under `android/app/src/main/res`.
- Do not place third-party or unlicensed images here.

For a store release, export density-specific PNGs from `app-icon.svg` and replace all `mipmap-*` launcher assets.
